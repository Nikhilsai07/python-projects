## Requirements

- Python 3
- Tkinter for GUI projects (often included with standard Python installations)
- Any additional packages required by an individual project

## Run a project

1. Install Python 3 from [python.org](https://www.python.org/downloads/).
2. Open the folder for the project you want to run.
3. Run its Python file from a terminal. For most projects:

   ```bash
   python app.py
   ```

   On some Windows installations, use `py app.py` instead. The crash-course folder contains individual example scripts; run the script you want to learn from.
